===word: 内存===
Meaning: computer memory, RAM
Nuance_EN: Refers to internal memory in computing, often used for RAM or storage capacity. Common in tech contexts.
Nuance_CN: 指计算机内部的存储空间，通常指内存条或运行内存，在科技讨论中常用。
Example1: 我的手机内存不够了，需要清理一些应用。
Example1_EN: My phone's memory is insufficient; I need to clear some apps.
Example2: 这台电脑的内存是16GB，运行速度很快。
Example2_EN: This computer has 16GB of memory and runs very fast.
Example3: 请检查一下内存使用情况，看看哪些程序占用了太多资源。
Example3_EN: Please check the memory usage to see which programs are taking up too many resources.
